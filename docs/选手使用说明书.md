## 快速开始（C++）

### 第 1 步：编写 AI

打开 `CAPI/cpp/API/src/AI.cpp`，在 `play` 函数中编写你的策略。

所有选手都会修改同一个 AI.cpp 文件。框架定义了 `AI` 类，继承自 `IAI` 接口：

```cpp
// AI.h 中的接口定义
class IAI {
public:
    virtual void play(ICharacterAPI& api) = 0;  // 单位控制（每帧调用）
    virtual void play(ITeamAPI& api) = 0;       // 队伍控制（每帧调用）
};
```

**你需要实现两个 `play` 重载：**

#### `play(ICharacterAPI& api)` — 单位控制

每个单位每帧调用一次。这个是**你的单位的大脑**：

```cpp
void AI::play(ICharacterAPI& api)
{
    // 1. 获取自己的信息
    auto self = api.GetSelfInfo();
    if (!self) return;

    // 2. 获取地图
    auto map = api.GetFullMap();

    // 3. 根据位置做决策
    int32_t cellX = api.GridToCell(self->x);
    int32_t cellY = api.GridToCell(self->y);

    // 4. 执行动作（示例：移动）
    api.MoveRight(200).get();      // 向右移动 200ms
    api.MoveDown(200).get();       // 向下移动 200ms
    api.Harvest().get();           // 采集资源
    api.Sell(THUAI9::GoodsType::Food, 1).get();  // 卖出商品
}
```

#### `play(ITeamAPI& api)` — 队伍控制

每个队伍只有一个 player 0 进程，负责**造单位、生产商品、升级科技**：

```cpp
void AI::play(ITeamAPI& api)
{
    auto team = api.GetSelfInfo();
    if (!team) return;

    // 造单位：Robot(1号), Drone(2号), AutonomousCar(3号)
    api.BuildCharacter(THUAI9::CharacterType::AutonomousCar, 1).get();

    // 生产商品
    api.ProduceGoods(THUAI9::GoodsType::Food, 1).get();

    // 升级科技
    api.UplevelTech(THUAI9::TechType::IncreaseEfficiency).get();
}
```

**重要规则**：
- `playerID = 0`：队伍控制进程，只有一个，执行 `play(ITeamAPI&)`
- `playerID = 1`：Robot（机器人），执行 `play(ICharacterAPI&)`
- `playerID = 2`：Drone（无人机），执行 `play(ICharacterAPI&)`
- `playerID = 3`：AutonomousCar（无人驾驶汽车），执行 `play(ICharacterAPI&)`

参考 `CAPI/cpp/API/src/AI.cpp` 中的默认实现（一个采集资源的自动驾驶车 AI）。

### 第 2 步：编译

用 Visual Studio 2022 打开 `CAPI/cpp/API.sln`，选择 **Debug** 或 **Release** 配置，点击 **生成 → 生成解决方案**。

编译产物：
- Debug：`CAPI/cpp/x64/Debug/API.exe`
- Release：`CAPI/cpp/x64/Release/API.exe`

### 第 3 步：运行

在项目根目录下双击对应的 bat 文件：

| 脚本 | 用途 |
|---|---|
| `start_thuai9_cpp_4teamversion.bat` | 4 队完整对战（每队 1 队控 + 3 单位） |
| `start_thuai9_cpp_1teamdebugversion.bat` | 单队调试模式（只启动 1 队 + 空队对手） |
| `start_thuai9.bat` | 旧版启动方式（ClientTest） |

脚本会自动：
1. 启动 UI（Avalonia 界面）
2. 启动 Server（游戏服务端）
3. 启动各队的 CAPI 进程

运行后会在多个终端窗口中分别显示各队/各单位的日志输出。

## 快速开始（Python）

### 第 1 步：编写 AI

打开 `CAPI/python/PyAPI/AI.py`，在 `CharacterPlay` 和 `TeamPlay` 方法中编写策略：

```python
from PyAPI.Interface import IAI, ICharacterAPI, ITeamAPI

class AI(IAI):
    def __init__(self, playerID: int):
        self.playerID = playerID
        self._team_phase = 0

    def CharacterPlay(self, api: ICharacterAPI) -> None:
        """单位控制，每帧调用一次"""
        me = api.GetSelfInfo()
        if me is None:
            return

        # 示例：向右移动 200ms
        api.MoveRight(200).result()

    def TeamPlay(self, api: ITeamAPI) -> None:
        """队伍控制，每帧调用一次"""
        team = api.GetSelfInfo()
        if team is None:
            return

        # 示例：造一个无人驾驶汽车
        api.BuildCharacter(THUAI9.CharacterType.AutonomousCar, 1).result()
```

详细 API 文档见 `docs/THUAI9_API接口文档_for_python.md`。

### 第 2 步：运行

```bash
# 单队调试（你控制 1 队，2 队为空）
start_thuai9_python_single_team.bat
```

环境变量可自定义：

```bash
set ACTIVE_TEAM=1        # 你的队伍编号（默认 1）
set DUMMY_TEAM=2         # 对手队伍编号（默认 2）
set GAME_TIME=120        # 对局时长（秒，默认 120）
set ENABLE_UI=1          # 是否启用 UI（默认 1）
start_thuai9_python_single_team.bat
```

## Python API 接口速查

Python API 与 C++ 接口一一对应，详细文档见 `docs/THUAI9_API接口文档_for_python.md`。

关键差异：
- Python 中 `Future<bool>` 需调用 `.result()` 获取结果
- Python 中枚举值通过 `THUAI9.XXX` 访问（如 `THUAI9.GoodsType.Food`）

## 游戏规则概要

详细规则见 `docs/规则.md`。以下为关键要点：

### 地图

- 50×50 格子，每格 1000 单位
- 地形：空地、草丛（可隐藏）、障碍（不可通行）、资源、算力中心、工厂、市场
- 四家工厂分布在地图四角

### 单位

| 类型 | HP | 伤害 | 移速 | 载重 | 特殊能力 |
|---|---|---|---|---|---|
| Robot（机器人） | 350 | 25 | 1000 | 20 | 范围伤害（半径 3 格） |
| Drone（无人机） | 100 | 30 | 1500 | 10 | 远程锁定（射程 5 格），无视草丛 |
| AutonomousCar（无人车） | 300 | 10 | 500 | 30 | 碰撞伤害，无法攻击无人机 |

- 额外造单位消耗：Robot 50 算力，Drone 40 算力，AutonomousCar 30 算力

### 商品

| 商品 | 成本 | 价值范围 | 耗时 |
|---|---|---|---|
| 半导体 | 10 | 40–120 | 5s |
| 药品 | 5 | 20–60 | 4s |
| 小商品 | 1 | 4–12 | 2s |
| 服饰 | 8 | 32–96 | 6s |
| 食品 | 3 | 12–24 | 1s |

### 科技

| 科技 | 消耗 | 效果 |
|---|---|---|
| 节约成本 | 50 | 除小商品外成本 −2 |
| 提高效率 | 40 | 任务耗时减半 |
| 营销手段 | 80 | 售价提高 10% |
| 增加耐久 | 30 | 耐久增加 50% |
| 战斗文明 | 10 | 伤害增加 30% |

### 算力

- 算力中心每秒产出 1 点，占领耗时 10s
- 用途：修复（1 算力 = 30 HP）、升级科技、向智慧大脑提问（5 算力/次）、造单位

### 市场

- 廉价市场：基础价值 ×2 收购
- 高额市场：基础价值 ×10 收购
- 贬值机制：单市场累计收购达阈值后降价

### 智慧大脑

- 每 180s 触发市场事件，商品价格乘数 0.5–1.5 波动
- 消耗 10 算力向 LLM 提问（最大 512 字符），获得 100 字内策略建议

### 得分

**得分 = 销售额 × 10 + 摧毁机器数 × 10000 + 摧毁工厂数 × 50000**

### 胜负

- 10 分钟对局，工厂 HP 归零则该队失败
- 按最终得分排名

## 常见问题

### Q: 编译 API.exe 报错？

A: 确认用 Visual Studio 2022 打开 `CAPI/cpp/API.sln`，并确保安装了"使用 C++ 的桌面开发"工作负载。编译目标选择 x64。

### Q: 运行时提示找不到 API.exe？

A: 先打开 `CAPI/cpp/API.sln` 编译一次，生成 `x64/Debug/API.exe`。

### Q: 如何查看日志？

A: C++ 启动时带 `-d -o` 参数会把日志保存到文件并输出到终端。Python 中带 `-o -d` 同理。C++ 日志文件在 `CAPI/cpp/logs/`，Python 在 `CAPI/python/logs/`。

### Q: 如何单步调试我的 AI？

A: 在 Visual Studio 中打开 `API.sln`，设置 API 项目属性 → 调试 → 命令参数：
```
-t 1 -p 1 -I 127.0.0.1 -P 8888 -d -o
```
然后先手动启动 Server 和 UI，再在 VS 中按 F5 启动调试。

### Q: 如何知道自己的分数？

A: 通过 `api.GetScore()` 获取当前队伍分数。单位也可通过 `api.GetGameInfo()` 获取各队全局信息。

### Q: AI.cpp 中有个 AI.backup.cpp 是什么？

A: 这是一个 API 测试用的备份文件，包含所有接口的调用示例，可以参考学习，但修改 AI 时请改 `AI.cpp`。

### Q: 移动单位时如何避免撞墙？

A: 使用 `api.GetFullMap()` 获取地图，`PlaceType::Barrier` 是不可通行格子，`PlaceType::Bush` 是草丛（可通行但会影响视野）。用 BFS 或 A* 算法规划路径。参考 `AI.cpp` 中的 `Bfs` 函数实现。

### Q: 哪些文件我可以改？

A: 你只需要修改 `CAPI/cpp/API/src/AI.cpp`（C++）或 `CAPI/python/PyAPI/AI.py`（Python）。其他文件请勿修改，否则可能导致评测时结果不一致。
